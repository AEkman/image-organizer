# Later improvements

These features are outside the first iteration.

- Add selectable visual themes.
- Add a focus mode with fewer visible action hints and shortcut labels, while keeping actions and keyboard help available.
- Browser fullscreen mode.
- Zoom in and out, actual-pixel inspection, and panning.
- Linked and independent zoom/pan in side-by-side comparison.
- Additional image formats, such as HEIC; prioritize exact formats after the initial version is usable.
- Remember rejection marks, review position and comparison selection across reloads and application restarts.
- Add a folder-picker button beside the editable folder path.
- Support folders containing thousands of images, including thumbnail loading and navigation appropriate to that scale.
